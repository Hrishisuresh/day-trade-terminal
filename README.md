# Day-Trade Terminal

A one-page trading terminal for gold, NAS100, US30, S&P 500, GER40 and UK100: live TradingView charts, order-flow footprint and volume profile (Binance and Alpaca), news-impact guide with Forex Factory forecasts, and the economic calendar.

Open it in Chrome on Android and choose **⋮ → Install app** to use it like an app.

API keys and the Forex Factory relay link are saved only in your own browser — never in this repository.
Not investment advice.
