# Day-Trade Terminal

A one-page trading terminal for gold, NAS100, US30, S&P 500, GER40 and UK100: live TradingView charts, order-flow footprint and volume profile (Binance), and an economic calendar with Forex Factory forecasts and official actual figures (BLS, Federal Reserve, Bank of England, ECB, ONS, Eurostat, FRED).

Open it in Chrome on Android and choose **⋮ → Install app** to use it like an app.

The relay link is saved only in your own browser — never in this repository.
Not investment advice.
