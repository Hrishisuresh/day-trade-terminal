Where the real volume & orders are

gold + your indices
Your CFD charts (OANDA here, and most brokers) only show tick volume: how many times the price changed, not how much was actually traded. Real volume and real order books live on the futures exchanges, so for each of your markets, check its futures contract. On TradingView these are free with a short delay; live data is a paid add-on.
Where the orders sit — gold: OANDA's Order Book shows where OANDA traders have pending buy and sell orders and open positions, price level by price level. It covers the last 24 hours and updates every 30 minutes. It's one broker's clients, not the whole market, but it shows where stops and limit orders cluster.
Where the orders sit — indices: the real order book (depth of market) for index futures needs paid live data through a futures broker. There's no free version. For the US ETFs above (SPY, QQQ, DIA, GLD), Cboe's free Book Viewer on cboe.com shows the top buy and sell orders and the last trades, but only for orders on Cboe's own exchanges (about a fifth of US share trading).
Free stand-in that works: add a Volume Profile to the futures chart. The fattest bars show the prices where the most trading happened, and price often reacts there. TradingView's built-in version needs a paid plan; free community versions exist (Indicators → Community → search "Volume Profile"). Stops also cluster above old highs and below old lows: previous day high/low, Asian range, equal highs/lows.
What the big players hold: the US regulator's Commitments of Traders report shows how large speculators are positioned in gold and index futures. Weekly — out Friday 15:30 New York, using Tuesday's data. CFTC COT ↗

How to read it. Each footprint cell shows sellers × buyers at that price inside that candle. Green box = buyers 3× sellers, red box = sellers 3× buyers, amber box = the candle's most traded price. Δ (delta) = buyers − sellers: price rising on negative delta is a warning sign. The profile shows where most volume traded: POC = most traded price, VAH/VAL = edges of the zone holding 70% of volume — they often act as support and resistance. News impact guide

usual first reaction — not a rule
The forecast is already in the price. Before each release, economists publish a forecast (the calendar shows it next to "Previous"). Traders position for it in advance.
Price moves on the surprise — actual minus forecast. Small surprise = small, quick move. Big surprise = big move that can run for hours.
When it hits: most of the move comes in the first 1–15 minutes after the release time. Spreads widen, and the first spike often fakes out (a stop hunt) before the real direction shows.
If it matches the forecast, expect a quick spike both ways, then price usually goes back to what it was doing before.

Load Forex Factory forecasts automatically (one-time fix)
Forex Factory's feed doesn't let web pages read it directly — Chrome blocks it. A tiny free relay in your own Google account fixes that for good. Or paste the feed in by hand once a week.
Option A — automatic (about 5 minutes, once; easiest on a computer)
  1. Open script.google.com signed in with your Google account. A new project opens.
  2. Delete everything in the code box, then press Copy code below and paste it in. Press the save icon.
  3. Top right: Deploy → New deployment. Click the gear next to "Select type" → Web app. Set Execute as: Me and Who has access: Anyone. Press Deploy.
  4. Press Authorize access and pick your account. Google warns "hasn't verified this app" because it's your own new script: click Advanced → Go to Untitled project (unsafe) → Allow.
  5. Copy the Web app URL (ends in /exec), paste it below and press Save & load.
function doGet(e) {
  var cache = CacheService.getScriptCache();
  var body = cache.get('ff');
  if (!body) {
    try {
      var r = UrlFetchApp.fetch('https://nfs.faireconomy.media/ff_calendar_thisweek.json', { muteHttpExceptions: true });
      var t = r.getContentText();
      if (r.getResponseCode() === 200 && t.trim().charAt(0) === '[') {
        body = t;
        cache.put('ff', t, 1800);      // fresh copy, 30 minutes
        cache.put('ffgood', t, 21600); // backup copy, 6 hours
      }
    } catch (err) {}
    if (!body) body = cache.get('ffgood') || '[]';
  }
  var cb = e && e.parameter && e.parameter.callback;
  if (cb && /^[A-Za-z_$][\w$]*$/.test(cb)) {
    return ContentService.createTextOutput(cb + '(' + body + ');')
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  return ContentService.createTextOutput(body)
    .setMimeType(ContentService.MimeType.JSON);
}
